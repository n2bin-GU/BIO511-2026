Additional CLI Practicals: Pathing

BIO511 Genomics - Navigating in bash

Author

Tor Kling

Published

August 1, 2026

Description

This additional segment exists for you to recap navigating the file system and to remember where you are within it. This is not obligatory, but if you are struggling with the LINUX filesystem, then it is highly recommended that you complete this.

Warning

Make some example directories to practice navigating the file system.

# In a suitable directory
mkdir pathing_test
cd pathing_test
mkdir dir1 dir2 dir3

# Make some files in each directory
touch dir1/file1.txt
touch dir3/testfile.txt
mkdir dir2/subdir1
touch dir2/subdir1/file2.txt

Directory Tree Structure

The linux file structure is hierarchical, starting from the root directory / and branching out into various subdirectories. Imagine a tree, we climb from the root by entering one of the directories from / (ex. /home). Entering different subdirectories from there is akin to climbing out along different branches of the tree.

For each directory, you can navigate using relative or absolute paths. A relative path specifies the location of a directory or file in relation to the current directory, a variable starting point or a symbolic link. An absolute path specifies the full path from the root directory, in the context of Linux’s “everything is a file” philosophy, this is also the true path of the directory or file.

You can list its contents to understand its structure. Using ls -la will show you something akin to the following output:

ls -la 

#Output
total 32
drwxrwxr-x 8 torkl torkl 4096 Sep 24 01:08 .
drwxrwxr-x 3 torkl torkl 4096 Aug  6 13:06 ..
drwxrwxr-x 3 torkl torkl 4096 Sep 23 17:16 cloned
drwxrwxr-x 3 torkl torkl 4096 Sep 24 01:06 gitlab_repository
drwxrwxr-x 3 torkl torkl 4096 Sep 18 13:49 Intro_to_CLI
drwxrwxr-x 3 torkl torkl 4096 Sep 24 00:05 my_project
drwxrwxr-x 3 torkl torkl 4096 Sep 24 01:10 testdir
drwxrwxr-x 3 torkl torkl 4096 Sep 23 23:33 Testrepo

The . represents the current directory, while .. represents the parent directory. Both of these can be used as relative paths when navigating the file system:

# Navigate to the parent directory
cd dir1
cd ..
ls -l

# Navigate to a another subdirectory from the parent directory
cd dir1
pwd 
# Output should show the current directory, ex., /pathing_test/dir1
# Navigate to the testdir directory from the parent directory using a relative path
cd ../dir2

# Navigate to a directory using an absolute path
pwd
# Copy the full path from the terminal output above and use it to navigate directly to the directory
cd "<full_path_to_directory>"

So a relative path would be ../my_project, an absolute path /home/user/Mydirectory/project/data/mydata.txt. When we use symbolic links (made with ln -s), we create shortcuts to directories or files, making navigation more convenient. Keep in mind that these are also relative paths to the symlinks themselves. So for some scripts (ex. those executed in a container), it is important to use the actual true path to the target file or directory rather than relying on the symlink.
