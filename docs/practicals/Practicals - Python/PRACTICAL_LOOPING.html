Introduction

Looping over different types of sequences is key in most programming languages and python is no different. Today the exercises will involve creating some simple loops followed by some more involved loop constructs where you will combine looping with the if clauses we learned yesterday.

While loops

A while loop is useful when you want to continue until an event happens. A for loop can solve the same problem when you count occurrences and stop with break.

Use this DNA sequence:

sequence = 'GATTACAGAACTGATAC'

Your task is to find the position of the third A in the sequence. Use zero-based indexing, so the first character is at position 0. The expected answer is:

The third A is at position 6

  1. Use a while loop.

    Start at position 0 and keep track of how many A bases you have seen. Use a_count < 3 as the condition for the while loop. Each time you inspect a base, increase the position by 1. When the loop ends, the third A has been found at the resulting position.

  2. Use a for loop.

    Solve the same problem again. Use a counter to keep track of the number of A bases found.

    • Hint: When the counter reaches 3, use break to stop the loop.

  3. Print the position of the third A for both solutions. Both solutions should give the same answer.

What is different about the two solutions? In the while loop, it checks whether you have found three A bases. In the for loop, you need to add the condition inside the loop yourself.

  1. Add a variable in the beginning of the code count_a = 3 and reuse that in both loops. You can now easily change the value for both loops. What happens if you look for the tenth A in the sequence?

Nested loops

sequences = ['ATCTGAGTCCACACATG', 'GCGTCGTGCGATGTTCACGTTGAT', 'CAGTAGTACTCAGT', 'GGTATGCTAGACGAGATCTAATA']
codons = ['CCA', 'TGT', 'GTA', 'TAG']
for sequence in sequences:
  for codon in codons:
    if codon in sequence:
      print(codon + " is in " + sequence)
  1. See if you can follow every line and work out how this example code works.

When working with loops within loops it can get a bit tricky to keep track of things. A tip is to write the steps down in plain text before writing the actual code.

Hint: Start codons are ATG and stop codons are TAA, TAG and TGA.

  1. Try to find a way to make sure that the start codon is before the stop codon in a sequence. Which sequence(s) have a start codon before a stop codon?

Loop through a dictionary

We can loop through a dictionary by defining two variables: both the key and value.

Example: Build a simple dict with the keys pat_001, pat_002 and pat_003 that has a value each. Here, the values are lists:

data = {
    'pat_001': ['bacZZt98', 'bac889Ytd'], 
    'pat_002': ['bac0GFrr'], 
    'pat_003': ['bac889Ytd', 'bacFq55Hj', 'bacZZt98']
}

# Loop through the dict printing each key and each value as a list.
for key_patient, value_bact_list in data.items():  
  print(key_patient)
  print(value_bact_list)

# add a line to see if the value (list) has the bacterial strain 'bac889Ytd'. 
# If it does it should return 'True'. If not, it should say 'False'.

for key_patient, value_bact_list in data.items():  
  print(key_patient)
  print(value_bact_list)
  'bac889Ytd' in value_bact_list

Exercise: Reverse the dictionary

The dictionary data links each patient to a list of bacterial strains. In this exercise, you will build the reverse relationship: each bacterium should be linked to the patients in which it occurs.

Work through the following steps. Do not import any additional modules.

  1. Collect the unique bacteria.

    Create an empty list called unique_bacteria. Loop through data and then through each patient’s list of bacteria. Add a bacterium to unique_bacteria only if it is not already in the list.

    Print the list. It should contain each bacterium once:

    ['bacZZt98', 'bac889Ytd', 'bac0GFrr', 'bacFq55Hj']

    Hint: Use the append() method and an if statement.

  2. Create the reverse dictionary.

    Create an empty dictionary called bacteria_to_patients. Use the list from step 1 to add each unique bacterium as a key. Give every key an empty list as its value.

    At this stage, the dictionary should have this structure:

    {
    'bacZZt98': [],
    'bac889Ytd': [],
    'bac0GFrr': [],
    'bacFq55Hj': []
}

    Hint: To check whether a bacterium is already a dictionary key, use if bacterium not in bacteria_to_patients.

  3. Add the patients to the reverse dictionary.

    Loop through data again. For each patient and bacterium, append the patient ID to the list belonging to that bacterium.

    Print the completed dictionary. It should look like this:

    {
    'bacZZt98': ['pat_001', 'pat_003'],
    'bac889Ytd': ['pat_001', 'pat_003'],
    'bac0GFrr': ['pat_002'],
    'bacFq55Hj': ['pat_003']
}

Errors and try/except

Errors are a normal part of programming. Python stops the program when it encounters an error unless we tell it how to respond.

Run this example and observe the error:

number = int('five')
print(number)

The int() function cannot convert the string 'five' into a number. This produces a ValueError.

Handling an error

A try block contains code that might cause an error. An except block says what to do if that error occurs.

try:
    number = int('five')
    print(number)
except ValueError:
    print('That is not a valid number.')

The program now prints a message instead of stopping with an error.
