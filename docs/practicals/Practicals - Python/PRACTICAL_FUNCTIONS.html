Practical 3: Python Functions

BIO511 Genomics - Python Functions (and more looping)

Author

Alvar Almstedt, Bart Edelbroek, Emma Västerviga

Published

August 1, 2026

Introduction

Functions are everywhere in Python and it’s time for you to start using them to take you to the next level!

If there are any built-in Python functions you have not seen or heard about before (for example isdigit() or max()), search online for the documentation. The official page docs.python.org has information on the built-in functionality that comes with the standard Python installation.

Two things to keep in mind:

  • A function has to be both defined with a def block and then called before the code inside it actually runs. Calling a function means running the function.
  • A function has its own namespace. Code outside the function cannot access the variables that only exist inside the function. If you want to use a value outside the function, the function needs to return it.

Example

Defining a function

def add_two_numbers(num_one, num_two):
    number_to_return = num_one + num_two
    return number_to_return

Calling the function

my_added_numbers = add_two_numbers(1, 1)

print(my_added_numbers) # will print 2

Exercises

Setup

All three exercises use the variables below. Copy them into the top of your script, outside of any function, and do not rename them.

# Provided inputs
nums = [3, -1, 7, 2, 9, 0, 4]
limit = 4
text = "Room 101: bring 2 apples & 1 banana."

# Global variables
count = 999
summary = "unset"
result = "unset"

The last three variables are global variables. In each exercise you will create a local variable with the same name inside a function. This lets you see that changing a local variable does not change the global variable with the same name.

Count numbers above a limit

Write a function that counts how many numbers in a list are larger than a limit.

  1. Define the function.

    Define a function named count_above that takes two arguments: seq and lim.

  2. Create a local counter.

    Inside the function, create a local variable named count that starts at 0.

  3. Count the numbers.

    Loop through seq. For each number that is strictly greater than lim, increase count by 1.

  4. Return the result.

    Return count from the function.

  5. Call the function.

    Outside the function:

    • Print the global count.
    • Call count_above(nums, limit) and print the returned number.
    • Print the global count again.

Why is the global count still 999, even though the function set a variable called count to 0 and then increased it?

Summarise a text

Write a function that classifies each character in a string as a digit, a letter or something else.

  1. Define the function.

    Define a function named summarize_text that takes one argument: s.

  2. Create a local dictionary.

    Inside the function, create a local variable named summary that holds a dictionary with exactly these keys: "digits", "letters" and "other". Each key should start at 0.

  3. Classify each character.

    Loop through each character in s and use an if/elif/else chain:

    • If the character is a digit, increase "digits" by 1.
    • Else, if the character is a letter, increase "letters" by 1.
    • Else, increase "other" by 1.

    Hint: Strings have the methods isdigit() and isalpha().

  4. Return the result.

    Return the summary dictionary.

  5. Call the function.

    Outside the function:

    • Print the global summary.
    • Call summarize_text(text) and print the returned dictionary.
    • Print the global summary again.

What counts as "other" in text? Check that the numbers add up to the length of the string using len(text).

Aggregate with a mode

Write one function that can calculate three different things, depending on a mode argument. This exercise combines a loop with nested if statements.

  1. Define the function.

    Define a function named aggregate that takes three arguments: seq, mode and threshold.

  2. Create a local result.

    Inside the function, create a local variable named result. Its starting value depends on mode:

    • If mode is "sum", start at 0.
    • If mode is "count", start at 0.
    • If mode is "max", start at None. This means “no qualifying value found yet”.

  3. Loop through the numbers.

    Loop through each number n in seq:

    • If n is negative, skip it.
    • If n is at least threshold:
      • If mode is "sum", add n to result.
      • Else, if mode is "count", increase result by 1.
      • Else, treat the mode as "max". If result is None or n is greater than result, set result to n.

    Hint: continue skips the rest of the current iteration and moves on to the next number.

  4. Return the result.

    Return result from the function.

  5. Call the function.

    Outside the function:

    • Print the global result.
    • Call the function three times and print each returned value:
      • aggregate(nums, "sum", limit)
      • aggregate(nums, "count", limit)
      • aggregate(nums, "max", limit)
    • Print the global result again.

What does aggregate(nums, "max", 100) return, and why?
